# Open365 开源选型方案

> 基于 2026-06-18 对 GitHub 的系统调研（73 个调研代理、64 个候选项目、逐个核实许可证）。
> 目标：用现成开源项目拼出 90%+ 替代 360 安全卫士，不重复造轮子。
> 面向：全球用户 + 企业客户 + 闭源专业版变现。

## 一、技术底座

**结论：没有任何宽松许可的一体化套件能直接 fork 当底座。必须"自己写壳 + 模块化集成各域最佳项目"。**

为什么不能直接 fork 现成套件：

| 候选套件 | 许可 | 为什么不行 |
|---|---|---|
| ChrisTitusTech/winutil | MIT ✅ | 深度绑定 CTT 品牌（MIT 不授商标），每周改结构，31 万行攻击面。只能摘 config json |
| Lil_Batti/Windows-Maintenance-Tool | MIT ✅ | 套件里捆了 **GPLv3** 游戏下载器，整 fork 会把 copyleft 带进闭源产品。只能剥离后集成 |
| RyTuneX / Winhance / optimizer | AGPL / PolyForm-Noncompete / GPL ❌ | copyleft 或"禁止做竞品"条款，法律禁区 |

**底座方案：**
- **GUI 外壳 = Tauri**（Apache-2.0 OR MIT，双许可含专利保护）。10-50MB vs Electron 200MB+，Rust 后端正好跑特权操作。你工作区已装 Tauri CLI。作为依赖引用，不 fork。
  - 备选 Neutralino（MIT，~2MB），但依赖宿主 WebView2，老 Windows 有坑。企业大盘选 Tauri 更稳。
- **特权执行层 = 自研 Rust core**。网络修复/清理/启动项/卸载/优化的实际动作，自己调 Win32 API/netsh/Installer COM。**这是核心 IP，必须自研可审计可回滚**。集成的开源项目主要贡献"该做哪些操作、扫哪些位置"的知识，而非直接 link 它们的 GUI。

## 二、按功能域选型表

| 功能域 | 选定项目 | 许可 | 集成方式 | 覆盖度 |
|---|---|---|---|---|
| **网络修复** | 自研 + ios12checker/Windows-Maintenance-Tool（netsh/DoH 片段）+ farrokhi/dnsdiag（选最快 DNS，打包二进制） | MIT/BSD-2 | 集成+打包 | **90%** |
| **垃圾清理** | builtbybel/FluentCleaner（winapp2.ini 解析器）+ guhcostan/windows-cleaner-cli（清理类别） | MIT | 集成代码 | **85%** |
| **隐私清理** | builtbybel/privatezilla（注册表禁遥测规则集，已弃坑但取规则） | MIT | 集成+自维护 | **80%** |
| **启动项管理** | botherder/go-autoruns 或 p0w3rsh3ll/AutoRuns（**只读枚举**参考）；**禁用写操作必须自研** | MIT/BSD-3 | 参考 | **75%** |
| **强力卸载** | **Klocman/Bulk-Crap-Uninstaller**（19.7k⭐，打包 exe 用 CLI 驱动）+ no-faff/InstallerClean（清 Installer 残留，中位回收 22GB） | Apache-2.0/MIT | 打包+集成 | **90%** |
| **杀毒** | 见第三节 | — | — | **40-70%** |
| **系统优化/debloat** | **Raphire/Win11Debloat**（48k⭐活跃，-Silent 当动作库）+ WinUtil 的 config json（剥光 CTT 品牌） | MIT | 集成代码 | **85%** |

**配套安全网（360 让用户敢点的关键）：每个破坏性操作前自动建系统还原点 + 自带回滚。** 这是这些单人/AI 项目最缺的。

## 三、杀毒（最难替代）

**纯开源做不出企业级查杀，用组合方案：**

> **主防护 = Windows Defender 管理面板**（调微软 `Start-MpScan`/`Get-MpThreat`/`Set-MpPreference` cmdlet）
> **+ 补充 = YARA 自定义规则扫描**（VirusTotal/yara，BSD-3，唯一 strong-yes）

用户得到世界级查杀引擎（微软维护），我们零引擎维护成本，完全合法。
- ❌ 不 bundle ClamAV（GPL-2.0，要进程隔离 + 履行再分发义务，且检出率低于 Defender）
- 专业版可加 YARA 企业规则库订阅当卖点

## 四、能替代多少 360

**日常高频功能 ~88-92%，覆盖普通用户 95% 的日常点击。**

做得到：清理 85% / 优化加速 85% / 网络修复 90% / 强力卸载 90% / 杀毒 70%（借 Defender）/ 启动项 75%

做不到（360 的护城河，开源拼不出，我们也不碰）：
- ❌ 自有云查杀引擎 + 病毒库（十几年样本积累）
- ❌ 实时主动防御 / 行为拦截 / 勒索诱捕（需内核驱动）
- ❌ 诈骗拦截 / 钓鱼网站库（庞大威胁情报网络）
- ❌ 漏洞修复自动打补丁（补丁筛选库）

## 五、必须避开的许可雷区

| 雷区 | 动作 |
|---|---|
| **GPL/AGPL 传染** | BleachBit、ClamAV 引擎、RyTuneX、optimizer 等**只能 reference-only，绝不复制代码/静态链接** |
| **PolyForm Noncompete** | **Winhance 碰都不碰**——许可明文禁止做竞品，而我们正是竞品 |
| **盗版工具** | Win-Debloat7 的 Extras 捆了 MAS 激活破解 + Defender Remover，**只取 Standard 模块** |
| **商标 ≠ 版权** | WinUtil 是 MIT 但 "Chris Titus Tech" 名字未授权，**剥光所有品牌字样** |
| **许可矛盾的仓库** | README 与 LICENSE 冲突、无 LICENSE 的仓库**全部 skip**，这些功能自己写几十行就有 |

**合规必做：** 建 `THIRD-PARTY-NOTICES.txt` 随产品分发，逐项保留每个被用项目的版权+许可文本。BCU(Apache) 要保留 NOTICE 署名。发布前跑 `cargo-deny check licenses` + `cargo-about` 生成完整依赖树 NOTICE。

## 六、下一步最小行动（PowerShell 雏形 → v1）

1. **搭壳（1-2 周）**：Tauri 起工程，前端 360 式卡片 UI（体检/清理/优化/网络/卸载/杀毒），Rust 后端定义特权 command 接口。现有 PowerShell 引擎先用 `run_elevated()` 包进去跑通。
2. **先做 3 个零许可风险高价值域（2-3 周）**：网络修复（纯 OS 命令）+ 强力卸载（打包 BCU + vendor InstallerClean）+ Defender 杀毒面板。最快"看起来像 360 且能用"。每个动作配 dry-run + 还原点。
3. **补清理/优化/启动项 + 合规底座（2-3 周）**：集成 FluentCleaner 解析器、Win11Debloat 动作库、自研启动项写操作。同步建 THIRD-PARTY-NOTICES，跑 cargo-deny。
4. **发布工程化（1-2 周）**：代码签名 + VirusTotal 预检 + Defender 误报申诉（debloat 脚本必被报毒）。接虾盘云激活（社区版免激活，专业版 USB 指纹 + ED25519，复用 U-Claw `.license`）。
5. **v1.0 + 塞 U 盘渠道（1 周）**：绿色版（参考 U-Hermes env 五件套便携），打包进 U 盘产品线，给装机店/老客户试用。

**总周期约 7-10 周到 v1。核心风险在第 4 步的 AV 误报和代码签名，要尽早启动。**
