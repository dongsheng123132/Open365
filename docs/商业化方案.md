# Open365 商业化方案

> 一句话：**开源核攒口碑和流量，闭源专业版 + 服务 + 渠道变现**。
> 基础功能永久免费开源（Apache-2.0），这是流量入口，不是收入来源。
> （技术选型与许可证依据见 [开源选型方案.md](开源选型方案.md)）

## 0. 开源核 + 闭源专业版（核心变现结构，类似 GitLab CE/EE）

调研结论：用现成开源积木拼出 ~90% 替代 360，自身用 **Apache-2.0**，
只集成宽松许可（MIT/Apache/BSD/MPL）项目，避开 GPL/AGPL。变现靠下面这条分界：

| 开源社区版（Apache-2.0，免费获客） | 闭源专业版（变现，不含任何 copyleft 代码） |
|---|---|
| 清理 / 网络修复 / 启动项 / 卸载 | **批量企业部署 + 集中管理控制台** |
| Windows Defender 管理面板 | **YARA 企业威胁规则库订阅** |
| 基础残留扫描 | **自动回滚 / 审计日志 / 定时巡检** |
| 单机使用 | **远程运维**（复用现有 remote-agent 栈）|
| — | **白标品牌定制** |

> 专业版授权**复用虾盘云激活体系**（USB 指纹 + ED25519 + 双节点），
> 和 U-Claw / U-Hermes 同一套 `.license` 共享机制，技术零新增成本。

## 一、为什么 Open365 有商业机会

1. **360 的反面就是卖点**：用户烦透了广告/弹窗/捆绑。"干净、开源、无广告"本身就是差异化定位，自带传播性。
2. **刚需且高频**：网络修复、垃圾清理、卸载是每台 Windows 电脑的长期需求。
3. **信任稀缺**：国产系统工具普遍被认为"流氓"。一个真开源、可审计的工具能建立稀缺的信任。
4. **你已有渠道**：U 盘绿色版（U-Claw / U-Hermes）、装机、虾盘云激活体系都能复用。

## 二、四条变现路线（可叠加）

### 路线 A：开源免费 + 专业版增值（推荐主线）
核心功能永久免费开源。专业版（闭源或单独授权）卖**省事**和**批量能力**：

| 免费版 | 专业版（收费） |
|--------|---------------|
| 手动逐台修复 | **定时自动**体检/清理/修复 |
| 单机 | **批量部署**（一个 key 管 N 台，给网吧/公司/装机店） |
| 基础残留扫描 | **残留一键清理** + 深度清理规则库 |
| 社区支持 | **远程协助 / 技术支持** |
| — | **白标定制**（换 logo/名字，给品牌方） |

> 复用你现成的**虾盘云激活码体系**做专业版授权（指纹绑定 key），技术上零新增成本。

### 路线 B：装机店 / 网吧 / 企业 服务费
- 工具免费，但"上门/远程把一批电脑装好、配好、定期维护"收服务费。
- 和你 U 盘装机业务天然重叠：装系统时顺手装 Open365 专业版，按台收。
- 企业版：域内批量推送 + 集中管控面板（这是 360 企业版在收的钱）。

### 路线 C：U 盘绿色版捆绑（你的强项）
- 把 Open365 放进 U-Claw / U-Hermes 的 U 盘里作为"电脑急救"工具，提升 U 盘整体价值。
- "插上 U 盘 → 一键修网络/清垃圾"是很硬的卖点，尤其对不懂电脑的用户。

### 路线 D：捐赠 / 赞助（辅助）
- GitHub Sponsors、爱发电、收款码。口碑好会有，但别指望它当主收入。

## 三、不能碰的红线（吸取 360/CCleaner 教训）

- ❌ **绝不**塞广告、弹窗、捆绑安装 —— 一旦做了，"开源干净"的人设崩塌，等于自杀。
- ❌ **绝不**偷传用户数据 —— 透明是唯一护城河。
- ❌ 免费版**不阉割到不能用** —— 免费版必须真的好用，否则没流量。
- ⚠️ 商标：用 **Open365**，不要用 "360" 字样做名字/logo，避免侵权。

## 四、落地节奏建议

**阶段 1（现在 → 1 个月）：开源 + 攒星**
- GitHub 开源，README 讲清"无广告替代 360"的故事。
- 重点打磨网络修复（最痛、最有传播点："一键解决微信能上网页打不开"）。
- 在 V2EX / 小众软件 / B站 / 知乎 发"我做了个开源的 360 替代"。

**阶段 2（1-3 个月）：GUI + 专业版**
- Tauri 做个干净的 GUI（引擎已 -Json 就绪，套壳即可）。
- 上专业版授权（接虾盘云 key），先卖"定时自动维护 + 批量"。

**阶段 3（3-6 个月）：渠道变现**
- U 盘捆绑、装机店分发、企业版集中管控。
- 接你现有的装机 / U-Claw 客户群做第一批付费验证。

## 五、收入预估逻辑（保守）

- 免费版纯获客，转化率按 1-3% 估。
- 专业版定价：个人 ¥9.9-29/年，装机店/企业按台或按授权数。
- 真正的钱在 **B 端（装机/网吧/企业批量）和 U 盘捆绑**，而非 C 端个人付费。

---

**结论**：Open365 不靠卖软件赚钱，靠的是"用开源建立信任 → 把信任转成 B 端服务和你已有 U 盘渠道的增值"。
这条路和你现在的 U-Claw / U-Hermes / 虾盘云体系完全咬合，是顺势而非另起炉灶。
